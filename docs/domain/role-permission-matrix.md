# Role Permission Matrix

本文件用于沉淀管理端角色、菜单、页面动作与权限点矩阵。当前仓库尚未初始化具体业务模块，可先按模板维护，后续随着页面和权限系统落地逐步补全。

## 维护原则

- 新增页面、菜单、按钮权限时同步更新
- 前端可见性与后端接口授权规则应保持一致
- 涉及审核、风控、财务、导出、批量操作时必须明确到动作级别

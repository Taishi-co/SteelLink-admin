### 一、角色权限管理

原来只有一个空列表，现在支持完整的角色增删改查，并且新增了菜单权限分配功能。

- 新增/编辑角色：填写角色名称、编码、描述、排序、状态
- 删除角色：二次确认后删除，同时清除关联的权限数据
- 权限分配：点击「权限」按钮，弹出菜单树勾选该角色可访问的功能模块

### 二、菜单配置管理

原来也是空壳，现在支持完整增删改查，表格改为树形展示父子层级关系。

- 新增/编辑菜单：选择上级菜单、填写名称、路径、图标、权限标识、类型、排序
- 树形表格：父菜单可展开查看子菜单，层级一目了然
- 删除菜单：二次确认

### 三、Header 布局优化

之前每个页面左上角标题区域上下两行，描述文字长的时候会溢出边框，右上角状态胶囊和头像也挤在一起很乱。

**优化前：**
- 标题 24px 加粗 + 描述换行，撑高 header
- 右侧元素间距过大，容易超出

**优化后：**
- 标题和描述同一行显示，header 高度从 72px 降到 56px
- 右侧状态胶囊和头像紧凑排列，不再溢出
- 描述文字超长时自动省略号截断

### 四、侧边栏菜单分组

之前 8 个菜单平铺，系统管理的 3 个页面都用同一个齿轮图标，分不清。

现在改为三个分组，各有独立图标：
- 系统管理：管理员管理、角色权限、菜单配置
- 业务管理：用户管理、企业审核
- 商品中心：商品管理、类目配置

## Exception Path

| 编号 | 场景 | 前置条件 | 步骤 | 期望结果 |
| --- | --- | --- | --- | --- |
| TC-EX-01 | 非冻结订单解冻 | 订单状态不是冻结 | 调用解冻接口 | 返回 400，不修改订单状态 |
| TC-EX-02 | 缺少冻结事件解冻 | 订单状态为冻结但无有效冻结事件 | 调用解冻接口 | 返回 409，不修改订单状态 |
| TC-EX-03 | 违约处理异常订单 | 订单状态为异常 | 调用违约完成处理 | 只更新违约记录和事件，不把订单改成已完成 |
| TC-EX-04 | 空菜单权限 | 后端菜单接口成功返回空数组 | 打开受保护页面 | 前端显示无权访问，不展示全量 fallback 菜单 |
| TC-EX-05 | 终态订单冻结 | 订单状态为已取消、已完成或已归档 | 调用冻结接口或打开订单详情 | 接口返回 409，前端不提供可执行冻结入口 |
| TC-EX-06 | 物流无运力终止 | 订单状态为 25 | 打开订单详情 | 状态和告警显示履约已终止，时间线物流竞价为失败、后续节点跳过 |
| TC-EX-07 | 资金风控拒绝 | 融资结果为 rejected 或存在 `financing_risk_rejected` 事件 | 打开订单详情 | 顶部展示托盘垫资流程终止告警和拒绝原因 |
| TC-EX-08 | 终止原因标准化 | 订单存在卖方拒单、买方取消、资金驳回或物流无运力 | 查询订单列表或详情 | 响应包含 `terminationReason`，前端展示终止原因、触发方和原因 |

# Feature Spec

## 基本信息

- Feature ID: `SL-ADMIN-FIX-BUILD`
- Feature 名称: 管理端前端打包失败修复
- 负责人: Codex
- 目标上线环境: 管理端前端构建链路

## 背景

当前管理端前端在执行 `pnpm build` 时失败，阻断了本地验证、Review gate 与后续 PR 合并。问题集中在前端页面的未使用导入和宽泛类型声明，属于工程构建与静态检查层面的阻断，不涉及业务接口或权限逻辑调整。

## 范围

### In Scope

- 修复导致 `pnpm build` 失败的 TypeScript 编译错误。
- 修复 `./harness/verify.sh` 中当前已暴露的前端 ESLint 阻断项。
- 补齐本次修复对应的 feature 文档与发布清单。

### Out of Scope

- 后端接口逻辑改动。
- 页面业务流程重构。
- 新增功能或权限策略调整。

## 页面与交互影响

- 受影响页面: `订单管理`、`用户管理`、`菜单管理`、`角色管理`、`企业审核`
- 受影响路由: 前端路由导出方式
- 受影响布局或导航: 无
- 受影响组件: 页面表格、树选择、路由入口
- 受影响交互状态:
  - 页面现有交互保持不变
  - 构建与静态检查恢复可执行

## 接口与数据影响

- 受影响接口: 无
- 请求参数或响应结构变化: 无
- 受影响服务层: 无
- 受影响状态管理: 无
- 受影响后端 handler/service/repository: 无
- 受影响数据库或缓存: 无
- 配置或环境变量变化: 无
- 构建或部署影响:
  - 前端 `pnpm build` 恢复通过
  - `./harness/verify.sh` 的前端阶段不再因当前修复范围内的问题阻断

## 权限与合规影响

- 受影响角色: 无
- 新增/调整权限: 无
- 是否影响审核、风控、日志留痕: 否

## 验收标准

1. `frontend` 目录下执行 `pnpm build` 成功。
2. `./harness/verify.sh` 的前端 lint、typecheck、test、build 阶段通过。
3. 本次修复不改变现有页面与路由的业务行为。

# 测试用例

## 订单状态映射测试

### 测试用例1：状态15显示正确性
- **前提**：订单处于状态15（待买方确认）
- **操作**：查看买家端订单列表和订单详情
- **预期结果**：状态显示为"待买方确认订单"，而非"物流竞价中"

### 测试用例2：状态16显示正确性
- **前提**：订单处于状态16（物流竞价中）
- **操作**：查看买家端订单列表和订单详情
- **预期结果**：状态显示为"物流竞价中"

### 测试用例3：确认按钮显示（状态14）
- **前提**：订单处于状态14（待卖方确认）
- **操作**：进入订单详情页
- **预期结果**：显示"确认订单"按钮

### 测试用例4：确认按钮显示（状态15）
- **前提**：订单处于状态15（待买方确认）
- **操作**：进入订单详情页
- **预期结果**：显示"确认订单"按钮

### 测试用例5：物流报价按钮显示（状态16）
- **前提**：订单处于状态16（物流竞价中）
- **操作**：进入订单详情页
- **预期结果**：显示"查看物流报价"按钮

## 时间线测试

### 测试用例6：时间线显示所有步骤
- **前提**：创建一个新订单
- **操作**：进入订单详情页，查看时间线
- **预期结果**：时间线包含"选择目的地仓储"步骤

### 测试用例7：时间线状态流转
- **前提**：订单处于状态12（待选择目的地仓储）
- **操作**：查看时间线
- **预期结果**："选择目的地仓储"步骤显示为当前步骤

## 完整流程测试

### 测试用例8：订单完整流程验证
- **步骤**：
  1. 创建订单 → 验证状态12显示"待选择目的地仓储"
  2. 选择目的地仓库 → 验证状态13显示"待仓库确认"
  3. 仓库确认 → 验证状态14显示"待卖方确认"
  4. 卖方确认 → 验证状态15显示"待买方确认"并有确认按钮
  5. 买方确认 → 验证进入状态2"待签合同"
- **预期结果**：所有状态流转正确，时间线显示完整

### 测试用例9：时间戳记录验证
- **前提**：完成多个订单状态变更
- **操作**：查看订单时间线
- **预期结果**：每个步骤显示准确的操作时间

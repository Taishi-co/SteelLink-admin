# SL-ADMIN-AI-PROCUREMENT-CONFIG Spec

## 背景

AI采购上线后，平台运营需要在管理端配置采购流程、模型解析、商品匹配、融资匹配和审核策略，避免把运营参数写死在前端或买家侧后端。

## 范围

- 新增管理端配置 API：
  - `GET /api/v1/ai-procurement/config`
  - `PUT /api/v1/ai-procurement/config`
- 新增管理端页面 `/ai-procurement/config`。
- 可配置内容：
  - 流程阶段启用、必经、排序、超时。
  - 模型供应方、模型名称、温度、Token、置信阈值。
  - 商品匹配权重、供应商优先级、价格容忍、推荐数量。
  - 融资开关、金额上下限、必需材料、自动提交审核。
  - 审核角色、人工复核阈值、风险关键词。

## 非范围

- 不实现真实模型密钥管理。
- 不实现 AI 采购单审核列表。
- 不修改买家侧前端页面。

# SL-ADMIN-PRODUCT-AUDIT-SEARCH-DIFF Spec

## 基本信息

- Feature ID: SL-ADMIN-PRODUCT-AUDIT-SEARCH-DIFF
- Feature 名称: 商品审核搜索筛选与字段核对视图
- 负责人: Codex
- 目标上线环境: prod

## 背景

管理端商品审核列表缺少有效搜索和筛选，运营需要翻页查找商品。商品详情和审核弹窗也缺少按字段核对的视图，审核人员难以快速判断本次提交关注哪些字段。

## 范围

### In Scope

- 商品列表增加关键字、审核状态、货品类型、企业 ID、仓储资源 ID、主品类、子品类筛选。
- 后端商品列表接口支持上述筛选参数。
- 修正商品状态返回与筛选逻辑，按真实商品状态 `0/1/2/3/4` 返回。
- 商品详情和审核弹窗增加关键字段核对表。

### Out of Scope

- 不新增商品历史快照表。
- 不修改卖家端商品提交逻辑。
- 不实现跨版本字段级历史追踪；当前仅展示审核关键字段的当前提交值。

## 页面与交互影响

- 受影响页面: 商品管理
- 受影响路由: `/product`
- 受影响布局或导航: 无
- 受影响组件: 商品筛选区、商品详情抽屉、商品审核弹窗
- 受影响交互状态: 查询、重置、查看、审核

## 接口与数据影响

- 受影响接口: `GET /api/v1/products`
- 请求参数或响应结构变化:
  - 新增筛选参数 `keyword`、`enterpriseId`、`category`、`subCategory`、`goodsType`、`warehouseServiceId`
  - `status` 按真实商品状态筛选
- 受影响服务层: `frontend/src/services/api.ts`
- 受影响状态管理: React Query 查询 key 包含筛选参数
- 受影响后端 handler/service/repository: `backend/internal/handler/handler.go`
- 受影响数据库或缓存: 无结构变更
- 配置或环境变量变化: 无
- 构建或部署影响: 需要重新部署管理端前后端

## 权限与合规影响

- 受影响角色: 管理员、运营、超管
- 新增/调整权限: 无
- 是否影响审核、风控、日志留痕: 不改变审核结论写入；增强审核前字段核对。

## 验收标准

1. 管理端商品列表可按关键字、状态、货品类型、企业、仓库和品类筛选。
2. 商品状态展示和筛选与真实状态一致。
3. 商品详情和审核弹窗能展示关键字段核对表。
4. 当前无历史快照时，页面明确展示“暂无历史快照”，不伪造前值。
